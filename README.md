# 📊 Online Retail Executive Dashboard (2011)

## 📌 Project Overview
This project analyzes online retail sales data using Power BI to identify revenue trends, customer behavior, and geographic demand patterns.

## 🔍 Key Insights
- Revenue peaked in November (~13.9%)
- Top 4 countries contributed ~70% of total revenue
- Demand highest in Netherlands and EIRE
- Customer revenue contribution shows moderate concentration

## 📊 Dashboard Features
- Revenue Trend Analysis
- Top Countries by Revenue
- Top Customers Contribution
- Global Demand Map
- Interactive Country Slicer
- KPI Cards

## 🛠 Tools Used
- Power BI
- DAX
- Data Cleaning
- Data Visualization
